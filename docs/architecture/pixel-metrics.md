# 像素尺寸与碰撞盒设计

本文为**待决策**的参考文档：瓦片尺寸与角色碰撞盒比例。决策后应将结论写入 ADR 并回写各模块文档。

## 1. 为什么这个决定重要

瓦片尺寸是美术、相机、UI、碰撞、动画的共同基准。它一旦确定，重做成本极高（所有精灵、所有地图、所有数值）。

## 2. 16×16 与 32×32 的差异

| 维度 | 16×16 | 32×32 |
|---|---|---|
| 美术工作量 | 低（像素少，细节要求低） | 约 1.5–2 倍（需更多细节支撑尺寸） |
| 可视瓦片数（虚拟分辨率 640×360） | 40 × 22.5 | 20 × 11.25 |
| 角色表现力 | 角色约占 1×1.5 瓦片，细节有限 | 角色可占 1×2 瓦片，面部/武器细节更充分 |
| 作物阶段表现 | 3–4 个阶段用色块即可辨认 | 需要更精细的阶段图 |
| 碰撞精度 | 瓦片小，贴墙手感更细腻 | 瓦片大，边缘更“块” |
| 地图文件体积 | 同等世界尺寸下瓦片数 4 倍 | 更小 |
| 性能 | 几乎无差异（都远低于瓶颈） | 几乎无差异 |
| 同类参考 | 星露谷、泰拉瑞亚（16） | 较多现代像素游戏、部分 HD-2D 风（32） |
| 适配 4K/高刷 | 缩放倍数大，像素感强 | 缩放倍数小，画面更“现代” |

### 两个可行组合

**方案 A（推荐）：16×16 瓦片 + 虚拟分辨率 640×360**

- 可视 40×22.5 瓦片，视野接近星露谷。
- 角色 16×24（1×1.5 瓦片），脚部碰撞盒 10×6。
- 优点：美术成本最低；视野宽，适合农场经营；像素风格明确。
- 缺点：角色细节少，武器/服饰变化不易辨识。

**方案 B：32×32 瓦片 + 虚拟分辨率 960×540**

- 可视 30×16.9 瓦片，视野略窄但更沉浸。
- 角色 32×48（1×1.5 瓦片），脚部碰撞盒 20×12。
- 优点：角色与作物细节充足，战斗动作更易读；适配 1440p/4K 更自然。
- 缺点：美术量翻倍；地图与动画资源体积增大；相机在屏幕小的时候视野偏窄。

### 混合方案（不推荐，但可行）

- 世界用 16×16，角色/道具精灵用 32×32 跨格绘制。
- 增加渲染与对齐复杂度，容易出现“半格偏移” bug，不建议 v1 采用。

## 3. 碰撞盒比例设计

碰撞盒与精灵尺寸解耦是必须的：精灵用于表现（可高于瓦片），碰撞用于移动与排序。

### 参考点与排序锚点

- 统一使用**脚底中心**作为排序锚点：`sortY = feetWorldY`。
- 精灵绘制时以脚底中心对齐到实体位置，避免“漂浮”与遮挡错误。
- 碰撞盒以脚底中心为基准向上偏移，使其覆盖“站立占位”。

### 三种碰撞盒方案

| 方案 | 尺寸（以 16px 瓦片、角色 16×24 为例） | 优点 | 缺点 |
|---|---|---|---|
| A. 脚部盒（推荐） | 10×6（宽 0.63 瓦片，高 0.38） | 贴墙/穿门手感自然；与瓦片碰撞契合；遮挡排序准确 | 头部可“进入”墙体视觉区域（可接受） |
| B. 全身盒 | 12×20 | 直观、实现最简单 | 门/窄道难通过；贴墙时视觉与碰撞不一致 |
| C. 圆形盒 | 半径 5 | 移动顺滑、无卡角 | 与瓦片网格对齐差；推箱/放置类交互不直观 |

**推荐 A**：脚部盒是星露谷类游戏的标准做法，兼顾手感与瓦片对齐。

### 推荐参数表

| 项 | 16×16 方案 | 32×32 方案 |
|---|---|---|
| 瓦片 | 16×16 | 32×32 |
| 角色帧 | 16×24 | 32×48 |
| 脚部碰撞盒 | 10×6 | 20×12 |
| 碰撞盒上沿距脚底 | 6 px | 12 px |
| 排序锚点 | 脚底中心 | 脚底中心 |
| 交互格偏移 | 朝向前方 1 格 | 同左 |
| 移动速度参考 | 90 px/s（走）/ 150 px/s（跑） | 180 / 300 px/s |
| 攻击范围（近战） | 24×20 px | 48×40 px |

## 4. 对模块的影响

| 模块 | 需要固定的事项 |
|---|---|
| M06 Rendering | 虚拟分辨率、像素缩放策略（整数缩放 + letterbox） |

| M13 Physics | 碰撞盒偏移与尺寸、瓦片碰撞查询 |
| M10 Animation | 帧尺寸与对齐点（脚底中心） |
| M16 Player | 移动速度、闪避位移（与瓦片成比例） |
| M17 Interaction | 目标格计算（面向偏移） |
| M09 UI | 虚拟分辨率下的字号与缩放 |

## 6. 其他相关开放项

- 角色是否为 4 向还是 8 向精灵（影响美术量约 2 倍）。
- 是否需要角色换装（分层精灵）——若有，16×16 方案下辨识度更低。
- 是否支持相机缩放（若支持，像素缩放必须为整数或双线性过滤，二者不能混用）。
