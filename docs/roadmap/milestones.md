# 实现里程碑

本文档定义从空仓库到可玩版本的阶段划分、交付物、验收标准与风险。阶段顺序不可随意跳过：每个阶段都为下一阶段提供稳定基础。

## 阶段总览

| 阶段 | 主题 | 涉及模块 | 优先级 | 工作量 |
|---|---|---|---|---|
| A | 能跑能画 | M00–M07 | P0 | M |
| B | 能走能撞 | M08–M13 | P0 | M |
| C | 能种能存 | M14–M19、M22 | P0/P1 | L |
| D | 能打 | M20、M21、M09 | P1 | L |
| E | 完整循环 | M23–M25 | P1/P2 | L |
| F | 工具化 | M26、M27 | P1/P2 | M |

工作量：S < 1 周，M 1–3 周，L 3 周以上（单人估算，仅供参考）。

## Phase A：能跑能画

**目标**：窗口打开、清屏、显示精灵、键盘控制一个方块移动。

交付物

- M00：`.sln`/`.vcxproj`、vcpkg manifest、Debug/Development/Release 配置、CI 编译。
- M01：`Result`、日志、断言、数学别名、哈希。
- M02：SDL3 初始化、窗口、事件泵、文件读写、时钟。
- M04：固定步长循环、`FrameContext`、暂停。
- M05：纹理/JSON 同步加载 + 缓存 + 句柄。
- M06：GL 上下文、纹理、精灵批处理、相机、虚拟分辨率。
- M07：键盘/鼠标动作映射、输入上下文。

验收标准

- [ ] 全新克隆后按 README 步骤可构建并运行。
- [ ] 1280×720 窗口，关闭按钮正常退出，无泄漏报告。
- [ ] 显示一张 PNG 精灵，像素无模糊。
- [ ] WASD 移动方块，帧率稳定 60 FPS。
- [ ] 1000 个精灵同屏仍稳定 60 FPS。
- [ ] 缺少资源时不崩溃，输出明确警告。

风险

- SDL3 + OpenGL 上下文创建在 Windows 上需要验证（WGL、glad 加载顺序）。
  已在 [M06 实测](../build/m06-render.md) 中验证：SDL3 的 `SDL_GL_CreateContext` 在可见与隐藏窗口上
  都能拿到 4.1 Core 上下文；引擎未使用 glad，改为自研 42 项 GL 函数表，因此不存在 glad 加载顺序问题。
- vcpkg 三配置（Debug/Release）与静态运行库的组合容易出现链接错误。

## Phase B：能走能撞

**目标**：瓦片地图、碰撞、相机跟随、动画、场景栈。

交付物

- M11：ECS、场景栈、渲染提取、原型。
- M12：JSON 瓦片地图、多图层、查询、可见区域渲染。
- M13：AABB、瓦片碰撞、轴分离移动、触发器、射线。
- M10：动画 clip、方向变体、动画事件。
- M08：音频设备、音效播放、总线音量（可延后到 D）。

验收标准

- [ ] 128×128 地图流畅滚动，无接缝。
- [ ] 角色 8 向移动，不穿墙，沿墙滑动自然。
- [ ] 相机跟随平滑，像素对齐无抖动。
- [ ] 走/跑/idle 动画切换无闪烁。
- [ ] 触发器能产生进入/离开事件。
- [ ] 1000 实体 + 100 碰撞体稳定 60 FPS。

风险

- 系统顺序与延迟销毁设计不当会导致崩溃或隐性 bug。
- 浮点碰撞误差导致卡墙。

## Phase C：能种能存

**目标**：完整的耕种循环与存档读档。

交付物

- M15：内容数据库（物品/作物/瓦片/配方）与引用校验。
- M18：物品栈、背包、快捷栏。
- M17：目标选择、工具使用、放置校验。
- M19：耕地、浇水、播种、生长、收获、世界对象。
- M22：日历、季节、天气、日夜（基础）。
- M14：单槽存档/读档、原子写入、备份。
- M09：HUD 与背包 UI（基础）。

验收标准

- [ ] 锄地→播种→浇水→等待生长→收获→入包，全流程可玩。
- [ ] 雨天自动浇水，换季规则正确。
- [ ] 存档后重启读档，作物阶段/浇水/背包/日期一致。
- [ ] 故意损坏存档能回退备份并提示。
- [ ] 删除被引用的内容定义时启动报错清晰。

风险

- 内容数据模型反复调整导致存档迁移成本。
- 按格存储与 ECS 的边界不清。

## Phase D：能打

**目标**：近战/远程战斗、敌人 AI、受击与死亡、战斗 HUD。

交付物

- M20：生命/伤害、攻击判定、投射物、无敌帧、死亡掉落、状态效果。
- M21：感知、追击/攻击状态机、A* 寻路、敌人生成。
- M16：玩家攻击/受击状态、耐力（可选）。
- M09：战斗 HUD、伤害数字（世界空间由 M06）。
- M27：控制台与物理调试绘制（可提前）。

验收标准

- [ ] 玩家可近战攻击并命中敌人，单次攻击只结算一次。
- [ ] 敌人能绕墙追击、丢失目标后返回、攻击有冷却。
- [ ] 玩家受击有无敌帧与击退，死亡进入 GameOver。
- [ ] 敌人死亡按掉落表产出物品。
- [ ] 20 个敌人同屏稳定 60 FPS。

风险

- 判定窗口与动画不同步导致手感差。
- 击退导致穿墙。
- A* 在大量敌人时卡顿。

## Phase E：完整循环

**目标**：主菜单→游玩→暂停→日终→保存→读档 的完整闭环，并加入 NPC/经济。

交付物

- M25：应用状态机、新游戏/读档、暂停、日终结算、死亡流程。
- M08：音乐与音效完整接入。
- M22：天气/光照完整。
- M23：对话、好感、任务（可裁剪）。
- M24：商店、出货箱、加工（可裁剪）。

验收标准

- [ ] 从主菜单开始新游戏，游玩一整天，睡眠结算，自动存档。
- [ ] 退出后重新启动，读档恢复到相同状态。
- [ ] 暂停菜单可保存、返回主菜单、调整音量。
- [ ] 与至少一个 NPC 对话并完成一个任务（若启用）。
- [ ] 卖出作物获得金钱并购买种子（若启用）。

风险

- M25 膨胀为上帝对象。
- 日终多模块结算的一致性与失败回滚。

## Phase F：工具化

**目标**：地图编辑与调试效率提升。

交付物

- M26：瓦片绘制、对象放置、属性面板、撤销/重做、保存/加载。
- M27：实体检查器、性能面板、时间控制、快捷命令、日志窗口。

验收标准

- [ ] 在编辑器内修改地图并立即在游戏中加载。
- [ ] 撤销 50 步不崩溃，脏标记正确。
- [ ] 调试命令可传送、给物品、生成敌人、跳转日期。
- [ ] 发布构建不包含编辑器与调试代码。

风险

- 编辑器范围蔓延，挤占玩法开发时间。

## 跨阶段工作

- 每个阶段结束都应能构建、能运行、有基本测试。
- 每个阶段更新 `docs/index.md` 的模块状态与本文档的验收勾选。
- 架构决策变更必须新增 ADR，不直接改历史决策。
- 性能基线在 Phase A 建立，之后每阶段回归一次。
