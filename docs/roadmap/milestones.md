本文档定义从空仓库到可玩版本的阶段划分、交付物、验收标准与风险。阶段顺序不可随意跳过：每个阶段都为下一阶段提供稳定基础。

> **当前状态（相机跟随 + 八向朝向补丁后）**：28/28 模块已实现；`fa_tests.exe` 为
> **543 用例 / 30281 断言**全绿；Debug / Development / Release × x64 零 warning，
> `fa_app.exe --frames 60` 三配置 exit 0，smoke 覆盖 M02–M27（Release 不含 M26/M27）。
> **模块已齐，但垂直切片尚未闭合**：真实美术/音频仍为占位，主菜单/暂停/存档 UI、
> 场景切换、完整存档应用、26:00 睡眠与死亡惩罚仍需接线。验收项按“已实测 / 未接线”
> 如实勾选，剩余工作见文末。

## Phase A：能跑能画

**目标**：窗口打开、清屏、显示精灵、键盘控制一个方块移动。

**当前状态：✅ 已完成。** 三配置可构建运行，窗口/事件/输入/渲染链路稳定。

交付物

- ✅ M00：`.sln`/`.vcxproj`、vcpkg manifest、Debug/Development/Release 配置、CI 编译。
- ✅ M01：`Result`、日志、断言、数学别名、哈希。
- ✅ M02：SDL3 初始化、窗口、事件泵、文件读写、时钟。
- ✅ M04：固定步长循环、`FrameContext`、暂停。
- ✅ M05：纹理/JSON 同步加载 + 缓存 + 句柄。
- ✅ M06：GL 上下文、纹理、精灵批处理、相机、虚拟分辨率。
- ✅ M07：键盘/鼠标动作映射、输入上下文。

验收标准

- [ ] 全新克隆后按 README 步骤可构建并运行：本地工作树三配置已实测；
  全新克隆与 GitHub CI 仍未在本轮复核。
- [x] 1280×720 窗口，关闭按钮正常退出，无泄漏报告。
- [ ] 显示一张真实 PNG 精灵：当前只有 catalog `color`/`tile` 生成的占位纹理。
- [x] WASD 移动方块，smoke 稳定约 60 FPS。
- [ ] 1000 个精灵同屏基准：smoke 约 1366 quad 稳定 60 FPS，但还没有正式基准脚本。
- [x] 缺少资源时不崩溃，输出明确占位/警告。

风险

- SDL3 + OpenGL 上下文创建在 Windows 上需要验证（WGL、glad 加载顺序）。
  已在 [M06 实测](../build/m06-render.md) 中验证：SDL3 的 `SDL_GL_CreateContext` 在可见与隐藏窗口上
  都能拿到 4.1 Core 上下文；引擎未使用 glad，改为自研 42 项 GL 函数表，因此不存在 glad 加载顺序问题。
- vcpkg 三配置（Debug/Release）与静态运行库的组合容易出现链接错误。
  **已实测通过**（`x64-windows-static-md`，三配置零 warning）。

## Phase B：能走能撞

**目标**：瓦片地图、碰撞、相机跟随、动画、场景栈。

**当前状态：✅ 已完成，大图基准待补。** ECS/地图/碰撞/动画/音频都可用；
相机已跟随玩家（死区 + 平滑），八向朝向已实现；8 向动画与大场景性能尚未正式验收。

交付物

- ✅ M11：ECS、场景栈、渲染提取、原型。
- ✅ M12：JSON 瓦片地图、多图层、查询、可见区域渲染。
- ✅ M13：AABB、瓦片碰撞、轴分离移动、触发器、射线。
- ✅ M10：动画 clip、方向变体、动画事件。
- ✅ M08：音频设备、音效播放、总线音量（已实现，无解码器）。

验收标准

- [ ] 128×128 地图流畅滚动，无接缝：app 只跑 40×23 地图，大图未做基准。
- [x] 角色 8 向移动：斜向归一化 + 八向朝向（45° 扇区）已实现；8 向动画仍未实现，
  斜向复用相邻主方向。
- [x] 相机跟随平滑：`Camera2D::follow()` 提供死区、指数平滑与限速，
  128×128 地图逐格跟随/四角夹取有测试；app 以玩家精灵中心为目标。
- [x] 走/跑/idle 动画切换无闪烁（clip 由代码构建）。
- [x] 触发器能产生进入/离开事件。
- [ ] 1000 实体 + 100 碰撞体稳定 60 FPS：未做正式基准。

风险

- 系统顺序与延迟销毁设计不当会导致崩溃或隐性 bug。
  **已缓解**：系统顺序在 app 固定，延迟销毁走 `CommandBuffer`。
- 浮点碰撞误差导致卡墙；已用 ≤4px 子步缓解，墙内生成仍可能穿模。

## Phase E：完整循环

**目标**：主菜单→游玩→暂停→日终→保存→读档 的完整闭环，并加入 NPC/经济。

**当前状态：🟡 流程已实现，界面/接线待补。** `GameFlow` 已跑通
“新游戏 → 暂停 → 保存 → 日终 → 死亡 → 复活 → 主菜单 → 读档 → 退出”；
但主菜单/暂停/存档 UI、场景切换与完整存档应用仍未接线。

交付物

- ✅ M25：应用状态机、新游戏/读档、暂停/对话、日终结算、死亡/复活、自动存档、退出。
- 🟡 M08：音效/总线已实现；音乐流与真实音频解码未接。
- ✅ M22：天气/光照基础完整。
- ✅ M23：对话、好感、任务（可裁剪）。
- ✅ M24：商店、出货箱、加工（可裁剪）。

验收标准

- [ ] 从主菜单开始新游戏，游玩一整天，睡眠结算，自动存档：
  流程与日终/自动存档已由 `runFlowDemo()` 跑通，但主菜单 UI 与 26:00 睡眠触发缺失。
- [ ] 退出后重新启动，读档恢复到相同状态：`LoadHandler` 只恢复日历，
  世界/背包/农田/叙事/经济仍未应用。
- [ ] 暂停菜单可保存、返回主菜单、调整音量：状态机与保存可用，菜单 UI 缺失。
- [x] 与至少一个 NPC 对话并完成一个任务（M23 smoke）。
- [x] 卖出作物获得金钱并购买种子（M24 smoke）。

风险

- M25 膨胀为上帝对象：已通过回调把世界重建/存档应用留在 composition root，
  流程层只做编排。
- 日终多模块结算：已固定为“推进时钟 → M24 → M23 → 自动存档”；
  自动存档失败时日期不回滚，调用方会收到错误。
- 完整存档应用涉及各模块 serializer，仍需一次定清格式与迁移。
