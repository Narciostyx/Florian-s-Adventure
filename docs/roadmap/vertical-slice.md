# 首个垂直切片

垂直切片的目标不是“做完一个系统”，而是用最小内容验证**完整玩家体验**：一天之内，玩家能种地、能战斗、能存档。

> **当前状态（玩法验证第二增量）**：28 个模块已实现。种植与战斗都已从脚本演示
> 推进到**可手动操作**：`--play` 进入干净会话，快捷栏 1–3 是锄头/浇水壶/种子，
> 左键使用，指向成熟作物自动收获；右键近战攻击，敌人死亡掉落并自动拾取。
> `--play-test` 会无头跑通
> 耕地→播种→浇水→5 天→收获，再击杀一个 dummy 并拾取掉落，失败返回非零。
>
> 仍缺：主菜单/暂停/存档 UI、林地第二张地图、商店/睡眠、完整读档、真实美术/音频。

### 立即运行

```powershell
# 可操作种植会话（需要窗口）
.\build\bin\x64\Debug\fa_app.exe --window --play

# 无头自检：种植 + 战斗/掉落，失败返回 1
.\build\bin\x64\Debug\fa_app.exe --play-test
```

操作：`WASD` 移动，`1–9` 选快捷栏，滚轮循环，左键使用当前工具/种子，右键攻击，
`E` 交互（占位），F3 统计，反引号控制台；控制台内 `time.addDays N` / `time.set HH:MM` 推进时间。

## 1. 切片目标

玩家在一个小型农场与相邻林地中：

1. 早晨起床，查看 HUD（日期、时间、金钱、生命、耐力）——HUD 已有日期/时间/金币/耐力，生命与主菜单仍缺。
2. 用锄头开垦 3 块地，播下萝卜种子，浇水——**已可手动完成**（快捷栏 1–3 + 左键）。
3. 前往林地，用剑击败 2 只史莱姆，拾取掉落物——**战斗与掉落拾取已可手动/自检**；
   林地第二张地图尚未实现，当前在农场地图用 dummy 验证。
4. 返回农场，收获已成熟作物（可通过调试命令推进时间）——**已可手动完成**；`time.addDays` 已提供。
5. 在出货箱卖出作物，获得金钱——经济服务可用，但没有出货箱实体/交互。
6. 回家睡觉，触发日终结算与自动存档——M25 有 `endDay()`，睡眠触发与存档应用未接。
7. 退出并重新启动，读档回到次日早晨——M14 存档服务可用，完整世界/背包读档未接。

## 2. 范围

**包含**

- 一张农场地图（约 40×30 瓦片）+ 一张林地地图（约 40×30）。
- 3 种作物：萝卜（4 天）、土豆（6 天）、草莓（8 天，再生）。
- 1 种工具：锄头；1 种武器：木剑；1 个浇水壶。
- 2 种敌人：史莱姆（近战）、蝙蝠（飞行/冲刺）。
- 1 个 NPC：商人（对话 + 商店）。
- 基础 HUD、背包、快捷栏、暂停菜单、主菜单。
- 日/夜循环、晴天/雨天。
- 单槽存档 + 自动存档。
- 基础音效与一首背景音乐。

**不包含**

- 季节系统（切片固定为春季）。
- 任务系统、好感度、节日。
- 加工、酿造、动物、钓鱼。
- 多地图大地图、传送网络。
- 手柄支持（架构预留，切片可不验证）。
- 编辑器（用 JSON 手工编辑地图）。

## 4. 完成定义（Definition of Done）

功能

- [ ] 上述 7 步流程可从头到尾完成，无阻塞性 bug（当前完成第 2、3、4 步）。
- [ ] 存档→退出→启动→读档，状态一致（位置、背包、作物、日期、金钱）。
- [ ] 玩家死亡后能回到主菜单或读档，不崩溃。
- [ ] 所有内容由 JSON 定义，改数值不需重新编译。

- [ ] 1920×1080 与 1280×720 下像素显示正确。

- [ ] 无未处理异常/崩溃；错误均有日志。
- [ ] Debug 构建零警告（`/W4 /WX`）。

## 6. 切片验收测试脚本

1. 启动游戏 → 主菜单 → 新游戏。
2. 确认 HUD 显示第 1 天 6:00、金钱 500、生命 100。
3. 走到田地，按使用键锄 3 格，确认出现耕地贴图。
4. 选择萝卜种子，播 3 格，确认种子消耗、作物出现。
5. 切换浇水壶，浇 3 格，确认浇水状态。
6. 前往林地，被史莱姆攻击一次，确认扣血与无敌帧。
7. 反击击杀 2 只史莱姆，确认掉落物可拾取。
8. 使用调试命令 `time.addDays 4`，确认萝卜成熟。
9. 收获 3 个萝卜，确认进入背包。
10. 在出货箱卖出，睡觉，确认次日金钱增加。
11. 退出游戏，重启，读档，确认第 5 天早晨状态一致。
